# DSH 插件整合包（EAC/AIO Suite）——10 天实施计划

## 一、调研结论（已实测确认）

- **官方桌面端**：`D:\deepseek官方桌面端\DeepSeek Harness.exe`，版本 **v0.2.0-rc.2**（正是目标 RC2 内核，2026-09-29 构建）；DSH_HOME = `C:\Users\HUAWEI\.dsh`，desktop profile 已初始化；全局 `dsh` CLI 0.2.0-rc.2、node 24、pnpm 均可用。
- **插件机制（官方 RC2）**：插件经 pnpm 装进 `~/.dsh/profiles/desktop/node_modules`，记录在 profile 的 `package.json`（`dsh.profile.bundles`）；「组合包」= 声明 `dsh.bundle.patch` 的 npm 包；兼容性由 `peerDependencies` 对 `@deepseek-ai/dsh` 强制预检，豁免走 profile 的 `compatibility.json`。
- **UI 机制**：React 18 slot 系统，插件可在**设置页注册自定义 tab**（`settings.plugins.tab`）；宿主侧插件注入 `pluginManager` 服务即可编程调用 `installBundle / setBundleEnabled / listBundles`——**批量安装与更新可完全实现**。
- **清单盘点**：EAC 主线 49 个内置插件（官方配套 12 + EAC 自研 14 + 社区 23），正式退役 8 个；19 个可 npm 直装，其余从 EAC 仓库 tag（v5.3.6，因 v6 重构已裁树）/ 上游 GitHub 重打包。AIO（aio-v1）9 插件 + 6 个第三方运行时包 + 10 款皮肤。全部 MIT（个别素材附加署名条款）。
- **退役排除清单**（8 项，已核实）：auto-compact(main)、plugin-marketplace、webui-market、zat-dsh-engine、third-party-thinking、tool-vision、settings-nav-custom、file-drop 旧版。

## 二、交付物与架构

**一个整合包插件 `dsh-plugin-suite`**（名字可改），用户在官方桌面端插件页安装这一个包，设置页即出现「整合包」tab：

1. **目录 catalog**（打包内置，离线可用）：`eac.json`（41 项在役插件）、`aio.json`（9+6 项）、`skins.json`（10 款，可选组默认不勾选）；每项含安装 spec（npm / tarball / git）、锁定版本、中英文描述、风险徽章。
2. **重打包管线**（构建脚本，可复现）：从 EAC v5.3.6 tag 提取插件目录 + 下载 npm 社区包 → **统一改写 peerDependencies 适配 0.2.0-rc.2** → `npm pack` → `dist/*.tgz` + SHA256，发布 GitHub Release。
3. **Host 半**（cordis 插件，Node 侧）：注入 `pluginManager`，RPC 提供 `list / install(pack, ids) / update / status / uninstall`；安装前自动快照 profile，失败自动回滚，批量串行队列 + 重试，处理 pnpm `pendingBuilds/allowBuilds` 与版本豁免。
4. **Client 半**（React 18）：注册 `settings.plugins.tab`；套餐大卡选择（EAC/AIO）、插件清单勾选（状态/来源/风险徽章）、安装进度环 + 实时日志抽屉 + stagger 动画 + 骨架屏、更新中心、卸载；CSS Modules 对齐官方设计 tokens，中英双语 locale。
5. **分发**：插件 tgz + 全部重打包产物发布 GitHub Release（公开、可复现构建）。

1. 在官方桌面端 **v0.2.0-rc.2** 安装整合包后，设置页出现「整合包」tab；界面精美、动画流畅（60fps 交互动画）、布局对齐官方设置页、中英双语。
2. 可独立选择 EAC 或 AIO 套餐，勾选后一键安装，过程有实时进度与日志；成功后插件默认启用，**RC2 上有问题项自动禁用并在界面标注原因**。
3. EAC 包覆盖 main 线全部在役插件 **41 项**（49 − 退役 8），最终版安装成功率 100%；不兼容项显式列出原因，不允许静默失败。
4. AIO 包覆盖 aio-v1 全部 **9 插件 + 6 第三方运行时包**；10 款皮肤为可选组。
5. 更新中心能检测新版本并完成升级，重启后新版本生效。
6. 所有安装前自动快照、失败自动回滚；卸载后 desktop profile 的 package.json/lockfile 完整、桌面端正常启动、既有插件不受影响。
7. 交付真机测试报告：每个插件在 RC2 上的启用状态 + 冒烟结果矩阵（日志/截图）。
8. 产物全部发布 GitHub Release（整合包 tgz + 重打包 tgz 集 + SHA256 + 可复现构建脚本）。

## 六、风险与对策

- **RC2 与 EAC 旧插件接口差异**（最大风险）：D5 提前做 client 加载 spike；重打包统一宽化 peerDependencies；问题项降级为禁用+标注。
- **EAC 仓库 v6 重构裁树**：从 v5.3.6 tag 提取；社区包优先用 npm 上游最新版。
- **pnpm 构建脚本拦截**（本机已有失败先例）：安装选项带 `approvedBuilds`。
- **外观类插件视觉异常**：逐个冒烟，异常者默认禁用。
- **本机 `~/.dsh/profiles/node_modules` 存在死链**：测试前记录，不碰用户既有数据；所有写操作先快照。
